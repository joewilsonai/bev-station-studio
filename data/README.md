# Your show goes here

Everything show-specific lives in this folder and `public/`, so the code stays clean.

| File | What it is |
|---|---|
| `episodes.json` | Your scripts: `[{ n, title, script }]` |
| `show.json` | Title, author, voices, short look notes |
| `*-LOCKED.md` | Character and setting notes |
| `agent-manual.md`, `luna-brief.md` | Rules for connected agents and the sidebar |
| `refs/`, `rooms/` | Reference pictures for characters and places |
| `seed-*.json` | Optional shots and Bank items to start with |

Character ids are set in `lib/draw.ts`. Only use likenesses you have permission to use.
